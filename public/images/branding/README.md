# Henderson's Coffee & Ice Cream — Official Branding Assets

## Logo File Placement
Place the official brand logo file in this directory with the exact filename:
`hendersons-logo.png`

### Asset Requirements:
- **Format**: PNG (with transparent background) or SVG
- **Recommended Minimum Dimensions**: 512x512 px (or vector SVG)
- **Color Profiles**: Full color gold/amber/dark roast, with high contrast suitable for dark backgrounds (espresso/walnut).
- **Status**: The website is configured to automatically display this official logo when present, falling back gracefully to the authentic text-based wordmark (`Henderson’s COFFEE & ICE CREAM`) in accordance with brand integrity guidelines.
